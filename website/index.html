Features

为逻辑而生的每一个细节

从发牌到结算，每个环节都由精确求解算法驱动。

四档难度阶梯

简单（1–6，恒可解）/ 中等（1–10）/ 困难（1–13 经典牌面）/ 超难（1–13 窄解），由易到难逐级进阶。

求解器驱动

按剩余牌数（4 / 3 / 2 张）给出精确解法提示；「无解」按钮判定开局，答错扣分，识别无解直接过关。

丰富的计分机制

难度系数 ×1 ~ ×2、时间奖励（剩余秒数 ×5）、完美 3 步 +300、连胜加成（连胜 ×100），鼓励连续解答。

每日一题

每天一局专属题目，连续通关累计得分与用时，冲击历史最佳 Top 3 排行。

数据分析

胜率、总局数、平均用时、当前连胜、最近 7 天活跃度，并按难度分列统计，每次进入自动刷新。

中英双语 & 自由配置

一键切换中 / 英界面，默认难度与「允许无解题」开关自由配置，贴近真实牌局。
